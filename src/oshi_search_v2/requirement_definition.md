概要
====================

アプリ名は「推しサーチ」。
推しの画像が定期的・自動的に見ることができるシステムである。

システム構成図
--------------------

割愛。


背景
--------------------

始業時や終業時、昼休みなどに癒やしを得るため。


定義
--------------------

- 推し : めっちゃ好きなキャラクター




アプリ要件
====================


フロー
--------------------

1. アプリが自動で画像をユーザーの環境に送信する
2. アプリユーザーが画像を見る
3. 癒やされる


規模
--------------------

- 運用
  - 土曜日の勉強会内で修正できる程度
- 利用者
  - saturday-night-fevers


時間
--------------------

日に数度。適宜調整の可能性あり。


指標
--------------------

- コスト : 月に100円程度を目標とする


範囲
--------------------

- AWS
- Discord(engineer_study_room > playground)


機能要件
====================

機能
--------------------

- 画像の収集にはGoogle 画像検索の結果を使う
- 表示先はDiscord
- 実行環境はAWSを用いる


画面
--------------------

- 管理画面などを作らないため割愛。
